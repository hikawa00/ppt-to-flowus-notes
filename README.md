# ppt-to-flowus-notes

A Codex skill for turning course PPTX and PDF material into bilingual, exam-oriented Markdown notes with a separate coverage audit. The workflow and rules are in [SKILL.md](SKILL.md); scripts, references, templates, and tests are kept beside it.

## Restore the skill

Clone or download this repository, then place the whole directory at:

```text
<notes-workspace>/.agents/skills/ppt-to-flowus-notes/
```

Keep `SKILL.md`, `scripts/`, `references/`, `assets/`, `agents/`, and `tests/` together. The study notes and original course materials are separate from this repository.

To update an existing Git clone, run `git pull` inside the skill directory. If restoring from a ZIP, replace the old skill directory with the extracted one after saving any local changes.
